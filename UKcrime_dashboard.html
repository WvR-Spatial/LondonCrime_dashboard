Method & limitations

Spatial binning

Points are binned to H3 cells — a fixed global hexagonal index. Because cells are globally anchored rather than derived from the viewport, a cell keeps the same identity as you pan, which is what makes caching, month-on-month joins and permalinks valid. Resolution steps with zoom (r7–r10).

Normalisation

All choropleths map crimes per km², using each cell's true geodesic area (h3.cellArea). Raw counts are not comparable across resolutions, and H3 cell area varies slightly with latitude and icosahedral distortion.

Class breaks

Crime density is strongly right-skewed. Quantile breaks (equal cell counts) maximise visual discrimination but are recomputed per view, so a colour is only comparable within the current extent. Fixed breaks use an absolute log-spaced scale and are comparable between places and months. Choose deliberately.

Concentration (location quotient)

LQ = (category share within cell) ÷ (category share across the loaded extent). LQ > 1 means the category is over-represented relative to that cell's total crime — this separates genuine specialisation from ordinary footfall effects. Cells with fewer than 5 crimes are suppressed, as the ratio is unstable at low counts.

Hotspots (Getis-Ord Gi*)

Gi* z-scores use binary first-order (k=1) contiguity weights including the focal cell. Zero-count cells inside the loaded extent are retained in the analysis set — excluding them would bias the statistic badly. Classes are the conventional 90 / 95 / 99% confidence bands.

Caveat: no false-discovery-rate correction is applied, so with thousands of cells some "significant" results are expected by chance. Gi* is also sensitive to bin size and extent (the modifiable areal unit problem) — change the zoom and the hotspots will shift.

Data & its limits

  • Locations are snapped to anonymised map points, not true incident locations. Fine-grained patterns partly reflect the snap grid, not offending.
  • Coverage is England, Wales and Northern Ireland plus British Transport Police. Scotland is not included.
  • Data lag is roughly two months; counts are recorded crime, so they measure reporting and enforcement as well as crime.
  • The API caps a single query at 10,000 crimes. The viewport is therefore tiled into H3 r6 requests, capped per view — the dashed outline on the map is the true loaded extent.

Architecture

Entirely client-side (static hosting, no backend). Tiles are cached in IndexedDB keyed by month|h3-cell, so panning back is free and a month already fetched never re-requests. All statistics are computed in the browser.
